# ADRs

Registro longo de decisões que têm alternativas que valem ser lidas (contexto → decisão →
consequências → alternativas). O log curto e completo fica em `.specs/STATE.md`; o número do ADR é o
número da AD (`docs/adr/<NNNN>-<slug>.md`).

As decisões herdadas do checkduplo (AD-010 … AD-098) têm o ADR longo, quando existe, no repositório
de origem (`CRM/docs/adr/`). Nenhum ADR próprio do Ethica ainda.
