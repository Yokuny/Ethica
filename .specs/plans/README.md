# Caixa de entrada de planos

Planos em andamento. O Claude Code grava aqui automaticamente (`plansDirectory` em
`.claude/settings.json`); outros agentes salvam aqui o plano antes de executar.

Ao concluir a tarefa, mova cada plano para `.specs/features/<slug>/plans/<YYYY-MM-DD>-<assunto>.md`
(skill `ethica-docs`). Plano que fica aqui aparece em "Planos não arquivados" no `docs/index.md`.
